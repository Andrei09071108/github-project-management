# Set up a personal GitHub Project

From the owner's Projects area, create a new Project using a table or blank layout. Name it IT Support Portal — Project Management. In the repository Projects tab, link the existing personal Project. In Project settings choose Public independently from the repository visibility and verify both public URLs signed out.

Edit the existing Status field to match the [Kanban policy](kanban-workflow.md). Add Priority as single select (High, Medium, Low), Estimate as number (hours), and Start date and Target date as date fields. Use the built-in Milestone field for the repository milestone. Keep these fields scoped to this Project.

Create Delivery Board grouped by Status. Create Prioritised Backlog as a table grouped by Priority, in High, Medium, Low order; show title, status, estimate, labels, milestone and dates. Create Delivery Roadmap using Start date and Target date; group by milestone where available. Save and reopen each view. Configure [native workflows](automation-guide.md) before adding issues.
