# GitHub Project Management
## Issue Tracking, Kanban & Delivery Planning

An independent, AI-assisted, single-author portfolio demonstration. A fictional team planning an IT support portal needs to decide which requests to tackle, what delivery means and how to show progress. This repository provides reusable intake and review templates and an operating guide for GitHub Projects.

Start with the [project overview](docs/project-overview.md), [setup guide](docs/project-setup.md) and [Kanban policy](docs/kanban-workflow.md). Hosted Issues, boards and delivery evidence are pending authorisation.
